KUKA youBot Mobile Manipulation

Planning and controlling a mobile manipulator to autonomously pick up and reposition a cube in CoppeliaSim.

Robotic Manipulation Python Modern Robotics Task-Space Control CoppeliaSim

Status: Completed · Fall 2025 (ME449)

View Repository on GitHub

Overview

This project implements a complete manipulation pipeline for a KUKA youBot in CoppeliaSim. The robot drives to a cube, positions its arm and gripper, grasps the cube, transports it across the scene, and places it at a desired final configuration.

The program generates a reference end-effector trajectory, tracks it with a feedforward-plus-PI controller, converts the commanded end-effector twist into arm-joint and mecanum-wheel velocities, and propagates the robot configuration through the simulation.

Optimized controller completing the standard pick-and-place task.

Challenge

The task couples a five-joint robotic arm with a four-wheel omnidirectional mobile base. Reaching the desired end-effector pose requires coordinating both systems while continuously correcting tracking error.

The controller must also follow a multi-segment trajectory that includes approaching the cube, descending to the grasp pose, closing the gripper, transporting the cube, and releasing it at the target. Poor gain selection can produce large tracking error or overshoot.

Approach

The implementation was organized around three milestones. NextState propagates the youBot configuration from wheel and joint velocities while enforcing actuator limits. TrajectoryGenerator creates the reference end-effector poses for the full pick-and-place sequence. FeedbackControl computes the commanded end-effector twist using task-space feedforward control with proportional and integral feedback.

At each timestep, the program evaluates the current pose and reference pose, computes task-space error, generates a desired twist, and maps that twist through the combined arm-and-base Jacobian to wheel and arm-joint velocity commands. The next robot configuration is then computed and logged for CoppeliaSim.

Result

The best-performing standard task used a feedforward-plus-PI controller with Kp = 30, Ki = 0.2, a 0.01 s timestep, and a velocity limit of 15. With these parameters, the youBot successfully tracks the trajectory, grasps the cube, transports it, and places it at the goal.

Best-tuned controller on the standard task.

The repository also includes an overshoot case and a custom-task case, demonstrating how controller tuning affects tracking and how the same manipulation pipeline adapts to a different cube start and goal configuration.
